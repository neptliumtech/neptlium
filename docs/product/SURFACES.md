# Implemented surfaces

This inventory records application entry points and boundaries on merged main. For source of truth on Vercel project/domain mappings, see [Vercel](../operations/VERCEL.md). For variables, see [Environment](../engineering/ENVIRONMENT.md).

| Surface                         | Entry points and audience                                                                                      | Identity, data and limits                                                                                                                                                                         |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Web](../../apps/web)           | Public `/`, `/products`, `/solutions`, legal and account redirects                                             | Marketing/content source and public links. Requires no privileged credentials. Auth entry links lead to the account experience.                                                                   |
| [Capital](../../apps/app)       | Customer `/auth/sign-in`, `/auth/sign-up`, `/onboarding`, `/dashboard`                                         | Supabase browser/session configuration and server API origin. Uses API-owned principal, profile and financial projections. Availability and financial permissions come from the API.              |
| [Treasury](../../apps/treasury) | Organization-facing `/auth/sign-in`, `/onboarding`, `/dashboard` and section routes                            | Supabase session boundary and configured application/API origins. Dashboard presents unavailable organization context where durable membership and canonical projections are missing.             |
| [Admin](../../apps/admin)       | Operator `/login`, `/dashboard` and operations/users/security subroutes                                        | Supabase session, persisted API-side administrative authorization and server API origin. The financial control plane enforces its own approvals and durable state.                                |
| [API](../../apps/api)           | Platform clients `/v1/health`, `/v1/platform/capabilities`, account/customer/admin routes and provider ingress | Public probes and protected bearer routes. Durable Supabase, provider adapters and allowed origin configuration. Production rejects memory authority.                                             |
| [Pay](../../apps/pay)           | Public `/`, `/i/[publicToken]`                                                                                 | Public presentation foundation. The intent route validates token shape and renders unavailable execution. It performs no invoice lookup, payment collection or settlement in the reviewed source. |
| [Docs](../../apps/docs)         | Public `/` developer guide                                                                                     | Source-authored content links to API capabilities and Status. It has no authenticated API console or privileged credentials.                                                                      |
| [Status](../../apps/status)     | Public `/` health and incident shell                                                                           | No configured public status backend in the implementation. The page renders unknown availability and no published incident history.                                                               |

Use `pnpm --filter @neptlium/<workspace> build` and `pnpm --filter @neptlium/<workspace> test` for each row. Workspace suffixes are `web`, `app`, `treasury`, `admin`, `api`, `pay`, `docs` and `status`. Web CI also runs `test:unit`. API's Vercel package check is `pnpm --filter @neptlium/api vercel-build`. Match [CI](../engineering/CI.md) for affected shared packages and database fixtures.
